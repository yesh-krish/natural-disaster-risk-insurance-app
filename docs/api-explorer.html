Reading the results

    
Response
api_version, status, data and meta appear on every v1 lookup. Model sources, units and assumptions stay in data; meta.request records the validated inputs.

    
Availability
HTTP 200 means the lookup completed. Always check status: unavailable means no usable model data; not_found means no station found. Missing data never becomes zero risk.

    
Address input
For point lookups, choose Street address or Coordinates. Extra spaces are cleaned up. Address requests go to the US Census geocoder; check the displayed matched address and approximate coordinates. Typos may prevent a match; spelling corrections are not guaranteed. No match or multiple matches stops the calculation.

    
Errors
400: invalid parameters. 404: unknown endpoint. 405: use GET. 422: no unique address match. 502: provider failure. Errors include error.code and error.message. Blank, repeated and unknown parameters are rejected.

    
Frequency
Curve frequencies are percentages. Wind (API key: cyclone) covers tropical cyclones only and describes historical annual frequencies. Heat uses 1991–2020 annual maximum daily air temperature in °C at a qualifying historical US station, with complete-year counts; point mode only. Its contributions are historical-frequency illustrations. Wildfire results are research estimates. Fireline intensity returns a native Texas kW/m statistic without annual probabilities or contributions. These are not live forecasts. Response generation time is separate from source/model dates.

    
Coverage
Flood depths require installed Texas tiles. Other hazards use their connected datasets and regional coverage. Area results use 25 samples; their mean is not the probability of an event anywhere in the rectangle.

    
Local use
This server listens on 127.0.0.1 and has no API keys. Requests may contact government providers. These are research calculations; contributions exclude fees and other pricing adjustments. See the API guide and Python example.
